# 환경과 입력 형식

## 기존 코드 위치

이 문서는 저장소의 `skill/monthly-incident-report/references/`에 있다. 여기서 프로젝트 루트는 `../../..`이다. 별도 설치한 스킬에서는 이 상대 경로 대신 실제 프로젝트 경로를 사용한다.

| 프로젝트 파일 | 역할 |
| --- | --- |
| `make_monthly_ppt.py` | 월간 차트, 요약 문구, 별첨2 상세표 및 페이지 분할을 생성하는 CLI |
| `launcher_monthly.py` | 엑셀 갱신과 PPT 생성을 실행하는 로컬 웹 UI |
| `requirements.txt` | Python 패키지 의존성 |
| `report_config.sample.json` | 회사별 파일명, 사업부와 셀·행 매핑의 예시 |
| `README.md` | 기반 도구와 실행 방법 |

기반 도구는 [WeeklyIncidentReport](https://github.com/sangmi-ra/WeeklyIncidentReport)다. 누락된 기반 파일을 임의로 구현하거나 사용자 요청 없이 내려받지 않는다. 이미 설치된 기반 도구가 있다면 그 경로를 사용한다.

## 의존성과 설정

- PPT 생성에는 월간 생성기와 같은 폴더에 기반 도구의 `make_ppt.py`, `appconfig.py`가 필요하다.
- 엑셀 갱신에는 `update_excel.py`가 필요하다. 월간 웹 런처에는 추가로 기반 `launcher.py`가 필요하다.
- 프로젝트의 Python 가상환경을 우선 사용한다. 패키지 설치가 필요한 경우 `requirements.txt`를 사용한다. `pywin32`를 포함한 전체 환경은 Windows를 기준으로 한다. 엑셀 갱신의 실제 Excel/COM 요구사항은 설치된 기반 코드를 확인한다.
- `report_config.sample.json`을 참고해 로컬 `report_config.json`을 준비한다. 기존 설정을 덮어쓰지 않는다. 샘플의 `사업부A` 같은 값을 실제 값으로 추측해서 채우지 않는다.
- 특히 `monthly.division_cells`에 실제 사업부 이름별 `narr`, `grade` 셀 매핑이 있어야 한다. 생성기가 이 키를 사업부 목록으로 사용하므로 매핑이 비면 사업부별 갱신이 누락될 수 있다.
- 전사·계열사 요약 셀은 `monthly.total_cells`, `monthly.affiliate_cells`에서 읽는다. 차트 행 매핑은 기반 도구와 회사 설정을 따른다.

## 입력 제약

- 엑셀에는 `요약` 및 기반 도구가 지정한 사업부별 차트 시트가 필요하다. 생성기는 `openpyxl.load_workbook(..., data_only=True)`로 수식의 저장된 계산값을 읽는다. 이 라이브러리가 Excel 수식을 재계산하는 것은 아니므로 오래되거나 없는 계산값은 먼저 적절한 환경에서 갱신해야 한다.
- 지난달 PPT는 월간 형식의 템플릿 겸 기본 비교본이다. 임의의 PPT는 사용할 수 없다. 최소한 표지와 사업부 차트 슬라이드(인덱스 0, 1, 2), `[별첨1]`·`[별첨2]` 식별 문구, 사업부명 및 기존 표 구조가 코드와 맞아야 한다.
- 주간 결과물은 기반 도구가 만든 상세표 형식을 사용한다. 월간 생성기는 주간 9열을 월간 8열로 변환한다. 다른 형식의 표를 강제로 처리하지 않는다.
- `--compare`를 생략하면 `--prev`로 신규 확정 장애를 비교한다. 비교가 요청된 경우 사업부별 비교표가 실제로 인식되는지도 확인한다.
- `--out`을 생략하면 지난달 PPT 폴더에 `YY년 M월 장애현황_기준일(YYYYMMDD).pptx`를 저장한다. 같은 기준일로 반복 실행하면 같은 이름을 사용하므로 결과 경로 충돌을 확인한다.

## 엑셀 갱신을 요청받은 경우

기반 `update_excel.py`와 실행 환경을 먼저 확인한다. 현재 월간 런처는 갱신기에 `--src`와 `--date`를 전달한다. 실행 전 설치된 버전의 인수와 백업 동작을 확인하고, 원본 보존을 위해 작업 사본을 사용한다.

```powershell
python update_excel.py --src "작업용 장애데이터.xlsx" --date "2026-08-11"
```

갱신이 성공하고 계산값이 저장된 엑셀의 실제 경로를 확인한 뒤 그 파일을 월간 생성기의 `--xlsx`로 전달한다. 갱신 실패 후 오래된 엑셀로 보고서 생성을 계속하지 않는다. 이 저장소에는 갱신기 구현이 없으므로 백업 여부나 계산 완료를 확인 없이 보장하지 않는다.

## 스킬 사용 범위

이 스킬은 기존 프로젝트를 실행하는 지침이다. Python 엔진, 기반 주간 모듈, 회사 설정, 입력 Excel/PPT는 번들에 포함하지 않는다. 프로젝트의 `skill/` 폴더가 각 도구에서 자동 탐색되는지는 별도 문제이므로, 바로 사용할 때는 이 `SKILL.md`의 경로를 명시해 읽도록 요청할 수 있다. 자동 탐색이 필요하면 대상 도구의 지원 스킬 경로에 `monthly-incident-report` 폴더를 설치하고 실제 프로젝트 경로를 제공한다.
