# 월간 장애현황 보고서

기존 `make_monthly_ppt.py`를 실행해 월간 보고서를 만든다. 보고서 계산이나 PPT 작성 로직을 AI가 다시 구현하지 않는다. Codex와 Claude Code의 파일 접근 및 명령 실행 기능으로 사용할 수 있으며, 다른 스킬이나 MCP 서버는 필요하지 않다.

## 실행 준비

- 이 저장소 안에서는 스킬 폴더 기준 `../..`가 프로젝트 루트다. 스킬을 다른 위치에 설치했다면 사용자가 지정한 프로젝트 경로 또는 현재 작업 공간에서 `make_monthly_ppt.py`를 찾는다. 개인 PC의 절대 경로를 고정하지 않는다.
- 최초 실행 또는 의존성·설정 오류가 있으면 [환경과 입력 형식](references/setup.md)을 읽는다. 이 저장소에는 기반 주간 도구가 포함되어 있지 않으므로 스킬 파일만으로 실행할 수는 없다.
- 기준일(`YYYY-MM-DD`), 갱신된 엑셀, 지난달 월간 PPT, 결과 경로를 확인한다. 기존 대화나 제공된 파일로 확인할 수 없는 필수 입력만 사용자에게 묻는다. 월 중 기준일은 해당 월 1일부터 기준일까지의 진행분(MTD)이다.
- 상세표까지 갱신하는 보고서에는 주간 결과물 PPT가 필요하다. 주간 결과물 없이 실행하면 별첨2는 지난달 템플릿 그대로 남으므로, 완성된 이번달 상세표라고 안내하지 않는다. 사용자가 전체 보고서를 요청했으면 주간 결과물을 확보한 뒤 실행한다.
- 신규 확정 장애 비교 기준은 기본적으로 지난달 PPT다. 별도 비교 파일을 제공하면 `--compare`로 전달한다. 지정된 입력 파일은 모두 존재하고 읽을 수 있어야 한다. 존재하지 않는 주간·비교 파일을 전달하고 계속 진행하지 않는다.
- 입력 파일과 결과 경로가 같지 않도록 한다. 기존 결과를 덮어쓰라는 요청이 없으면 사용 가능한 새 파일명을 선택한다. 실제 장애 내용이나 회사 설정을 스킬 패키지·버전 관리에 포함하지 않는다.

## 보고서 생성

프로젝트 루트에서 해당 프로젝트의 Python 환경을 사용한다. 아래 파일명과 기준일은 예시이며 실제 입력으로 바꾼다. 공백이 있는 경로는 각 인수로 안전하게 전달한다.

```powershell
python make_monthly_ppt.py --date "2026-08-11" --xlsx "갱신된 장애데이터.xlsx" --prev "지난달 장애현황.pptx" --weekly "주간 결과물.pptx" --out "이번달 장애현황.pptx"
```

- 별도 비교본이 있으면 `--compare "비교본.pptx"`를 추가한다.
- 사용자가 상세표 유지에 동의한 차트·요약 갱신 작업이면 `--weekly`를 생략할 수 있다.
- 결과 위치를 확실하게 하기 위해 `--out`을 지정한다. 기본 동작 및 다른 옵션은 `make_monthly_ppt.py`의 `parse_args()`를 따른다.
- 입력 엑셀이 이미 갱신되어 있으면 엑셀 업데이트를 반복하지 않는다. 엑셀 갱신 요청이 있으면 먼저 참고 문서의 갱신 절차를 따른다.
- 오류가 발생하면 종료 코드와 필요한 로그로 원인을 확인한다. 누락된 모듈·설정·입력을 명확히 알리고, 실패한 실행을 성공으로 보고하지 않는다. 로그에는 고객명·장애 제목이 포함될 수 있으므로 답변에 원문 전체를 복사하지 않는다.

## 결과 확인과 전달

- 종료 코드가 0인지, 지정한 결과 파일이 생성되었는지 확인한다. `python-pptx`의 `Presentation`으로 결과를 다시 열어 슬라이드가 있는지 확인한다.
- 실행 로그에서 사업부 차트·표지 갱신 수와 별첨2 처리 결과를 확인한다. 요청한 갱신 수가 0이거나 별첨2가 미갱신이면 설정·템플릿 구조를 확인하고 불완전한 결과임을 알린다.
- 상세표를 갱신했다면 사업부별 등급확정·협의중 건수와 페이지 순서를 입력 PPT 및 로그와 대조한다. 신규 확정 건수는 단순 총건수 차이가 아닌 발생일·고객·제목의 항목 비교로 산정하므로 기존 로직을 유지한다.
- 렌더링 또는 PowerPoint 열기가 가능한 환경이면 차트, 한글 글꼴, 표 넘침, 별첨2 페이지 라벨을 확인한다. 파일을 다시 여는 것만으로 시각 검증이 완료되었다고 하지 않는다.
- 결과 파일 링크, 기준일, 사용한 비교 기준, 미갱신 항목과 검증하지 못한 부분을 간결하게 전달한다.
