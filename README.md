# Monthly Incident Report Generator (월간 장애현황 PPT 생성기)

엑셀 장애 데이터로부터 **월간 "장애현황" PowerPoint 보고서를 자동 생성**하는 도구입니다.
기존의 *주간* 장애보고 자동화 도구를 **월간 보고서 형식으로 확장**한 결과물입니다.

> **기반(Base)**: 이 프로젝트는 동료가 만든 주간 장애보고 자동화 도구
> [`WeeklyIncidentReport`](https://github.com/sangmi-ra/WeeklyIncidentReport) 를 토대로 합니다.
> 본 저장소에는 **제가 추가로 작성한 "월간 확장" 부분**만 담았습니다.
> (주간 도구의 `make_ppt.py`·`appconfig.py` 등은 위 원본 저장소를 참고하세요.)

---

## 배경 & 문제

매달 사람이 손으로 만들던 월간 장애현황 보고서(15장 내외)는

- 사업부별 3개년 추이 라인차트 갱신
- 표지·별첨의 거버닝 메시지 문구 갱신
- 사업부별 장애 상세 목록 표 재구성·정렬·페이지 분할

를 매번 반복해야 했고, 누락·정렬 실수가 잦았습니다. 주간 도구가 이미 있었지만
**보고서 성격(주간 공유 ↔ 월간 현황)** 과 **레이아웃**이 달라 그대로 쓸 수 없었습니다.

## 접근

> **"주간 도구의 검증된 엔진은 재사용하고, 월간 고유 로직만 얹는다."**

기존 주간 코드를 **전혀 수정하지 않고**(`import` 재사용), 월간 전용 생성기를 **별도 모듈**로 분리했습니다.

### 구현한 기능

- **3개년 추이 라인차트 갱신** — 기준일이 속한 달까지 개월 수를 확장. 외부 링크 차트의
  XML 캐시를 직접 재작성(트렌드라인·서식 보존)하는 주간 도구 로직을 재사용.
- **별첨1 연도밴드 자동 정렬** — 개월 수가 늘면 회색 연도밴드·`'24/'25/'26` 라벨을
  기준연도 앵커 기준 비율로 재배치(차트의 카테고리 압축과 동일한 변환).
- **표지/거버닝 메시지 자동 작성** — 요약 시트 셀에서 문구를 읽어 채우고,
  `-` 부호 기반으로 "증가/감소"를 자동 확정, 천단위 콤마 정리.
- **별첨2 사업부별 상세표** — 주간 결과물의 "장애 목록 상세"에서 **해당 사업부 행만**
  가져와 구성(주간 9열 → 월간 8열로 컬럼 remap). 등급→발생일 정렬.
- **용량 기반 페이지네이션** — 표가 한 장을 넘치면 슬라이드를 복제해 **해당 사업부 자리
  바로 뒤에 순서대로 삽입**, 페이지 라벨 `(i/N)` 자동 재넘버링.
- **전월 대비 신규 확정 N건** — 비교 파일과 **항목 단위로 매칭**(발생일 + 고객/제목)해
  현재에만 있는 새 항목 수를 산정(단순 건수 차가 아닌 항목 비교).
- **설정 외부화(보안)** — 사업부명·셀/행 매핑·파일명 등 회사 고유값을
  소스에서 분리해 `report_config.json`(git 미포함)에서 로드.

## 기술 스택

- Python, [`python-pptx`](https://python-pptx.readthedocs.io/), `openpyxl`
- 표준 라이브러리 `http.server` 기반 로컬 웹 런처 (무설치)

## 실행 방법

> 이 저장소는 제 기여분만 담고 있어, 실행하려면 기반 도구
> [`WeeklyIncidentReport`](https://github.com/sangmi-ra/WeeklyIncidentReport) 의
> `make_ppt.py`·`appconfig.py` 와 **같은 폴더**에 두고, `report_config.sample.json` 을
> `report_config.json` 으로 복사해 실제 값을 채우세요.

```bash
# 웹 런처 (권장)
월간보고_실행.bat        # 더블클릭 → 브라우저 UI

# 명령줄
python make_monthly_ppt.py --date 2026-08-11 \
    --prev   "지난달 장애현황.pptx" \
    --weekly "YYYYMMDD_주간결과물.pptx" \
    --compare "지난달 장애현황.pptx"
```

## 설계 노트

- **기존 코드 무변경 원칙** — 주간 도구 파일은 건드리지 않고 헬퍼만 `import` 하여,
  드롭인(파일 몇 개 추가)만으로 월간 기능이 붙도록 설계.
- **회사 고유값 분리** — 소스에는 실제 사업부명·파일명이 없고, 모두 외부 설정에서 로드.
  `report_config.json` 은 `.gitignore` 로 제외(샘플만 포함).
